# ГеоСрбија — Квиз о географији Србије 🇷🇸

Офлајн Android квиз апликација (`rs.geosrbija`) за телефоне и таблете (Android 5.0+ / SDK 21+), оптимизована и за старије таблете попут Samsung Galaxy Note 10.1 (`GT-N8020`) као и за новије телефоне.

## Инсталација (APK)
Спреман и потписан APK фајл налази се директно у репозиторијуму:
- [`GeoSrbija.apk`](./GeoSrbija.apk)

Инсталација преко `adb`:
```bash
adb install -r GeoSrbija.apk
```

## Карактеристике
- **6 рунди квиза (153 локације широм Србије укључујући АП Војводину и АП Косово и Метохију):**
  1. Велики градови
  2. Мањи градови
  3. Манастири
  4. Планине
  5. Варошице и села
  6. Реке
- **5 нивоа тежине:** *Туриста (Почетник)*, *Излетник (Аматер)*, *Планинар (Средњи)*, *Географ (Тежак)* и *Чувар Србије (Експерт)*.
- **Закључавање рунди по поенима:** Прелазак у наредну рунду захтева освајање прописаног броја поена за изабрани ниво тежине.
- **Звучни ефекти и пауза током игре.**
